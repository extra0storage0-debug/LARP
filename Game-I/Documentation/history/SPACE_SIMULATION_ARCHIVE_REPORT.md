## Island runtime dependency changes

- Redirected shared vector `cross`, `dot`, and rotation helpers from the removed globe module to `game.island_frame`, which already provides the same functions for the island.
- Removed unreachable spaceflight speed changes and cloud-deck takeoff behavior from `GameManager`.
- Removed the camera’s unreachable non-landable-planet framing and space FOV transition. Island camera pitch, distance, and speed FOV behavior remain the same within the island’s 500 m altitude range.
- Removed space-transition blending from the active island sky shader and retained the day/night cycle, atmospheric sky, night stars, and island sunlight.
- Updated the remaining lighting capture utility to capture only reachable island day, dusk, and night states.
- Kept the shared island coordinate-frame interface (`game.planet` at runtime), character movement, powers, collisions, world generation, settings, and game systems in their active locations.
